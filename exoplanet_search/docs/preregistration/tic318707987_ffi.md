## Expected S

S_exp = depth / (CDPP_D / sqrt(N_tr)). With depth 350 ppm and N_tr = 0, **S_exp = 0 <= 7: the test is
non-decisive in advance.** For reference, had the star been on silicon: the S70 FFI photometry through the same code
gives CDPP at D = 0.06 d of 101 ppm, and ~2 x 22 transits would give S_exp ~ 350 / 101 x sqrt(44) ~ 23.

## Criteria (fixed before any light curve from a test sector is examined; apply to any future sector)

* Period tolerance: blind peak (or the best peak within 0.5% of P) at |P - 0.95955| < 3 sigma_P (Delta S^2 = 1 width) and within 0.5%.
* Phase: FFI-only T0 within 2 sigma of the S70 ephemeris propagated with its period error; if the propagated error
  exceeds 0.25 P the phase test is reported as uninformative and only period + depth are used.
* Depth-consistency window: depth at the S70 ephemeris consistent with 350 ppm within 2 sigma (epoch-scatter error)
  **and** within 0.6x-1.6x of 350 ppm (dilution differences between apertures).
* **Recovered**: S_exp > 7, measured S at P >= 7, period and depth criteria met, the candidate period ranks first
  (or within the top 3 with no unrelated peak above it) in the blind search.
* **Ruled out**: S_exp > 10 and the depth at P is < 350 ppm by more than 3 sigma (equivalently, measured S < S_exp - 3).
* **Inconclusive**: anything else, including S_exp <= 7.
