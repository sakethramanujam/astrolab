# v1.1 amendment: known-planet gate scoring (2026-11-12). POST HOC

**Post hoc.** **Approved by Saketh 2026-11-12 11:52 AM PT.** Changes only how the known-planet gate is scored
(`exosearch/v11/known_planets.py`, the `known_planets` section of `configs/v1.1.json`). The search, the beta rule,
S* = 11.82 (option b) and every vetting threshold are unchanged; the search-path hash stays
`fb958a4e3287588b376c6f57c752c0e130ffb9d3d581840e476a165c7e23ae07`.

## Why
The sector 70 gate (frozen list `docs/preregistration/v1.1_known_planets_2026-11-12/`, f27e8cf; production commit
0e2ca0de) **failed: 17 of 95 required planets recovered** under the registered rule (amendment 2026-11-11, Section 3:
peak period within the period-grid plateau half-width). That half-width is a grid-degeneracy width (about 0.0004 d for
WASP-28 b), not a period error; 55 misses had the right period outside it. Other causes: planets with exactly 2
transits are eligible but always fail the 3-transit vetting screen; expected S over-predicts observed S.

**The S70 known-host results were seen before this amendment.** S70 therefore cannot be a clean test of the amended
gate. The clean test is **sector 71**: its expected-S list is frozen and pushed under these rules before any S71
search output exists.

## The five changes
1. **Period tolerance** = sqrt((D x P / T_span)^2 + (3 sigma_P)^2): D the catalogue transit duration, P the catalogue
   period, T_span the star's own searched data span (first to last detrended cadence, recorded in the frozen file),
   sigma_P the catalogue period error (pscomppars `pl_orbpererr1`, ExoFOP `Period (days) err`; 0 when absent).
2. **At least 3 transits** surviving the masks for eligibility, matching the vetting screen (`min_transits` = 3).
3. **Only confirmed planets (pscomppars, transiting) are in the pass/fail group.** Active TOIs are still frozen,
   searched and scored (period, S, vetting, losing stage) but are decided by their ExoFOP TFOPWG disposition, not by
   this gate. TOI 317.01 is out pending disposition; TOI 4542.01 and TOI 4543.01 fall under this item.
4. **Expected S x 0.66**, the observed/expected S ratio measured on injections: v1.0.0 `injection_v1` products, runs 0
   and 1, 10,139 injections; median S_obs/S_exp = 0.656 for the 3,681 period-matched injections with S_exp >= 15
   (0.674 for all 4,525 matched). Both the raw and the scaled value are frozen.
5. **Flagged 2x and 1/2x aliases count as recovered**, with the tolerance of item 1 evaluated at the alias period
   (ratio x tolerance; both terms scale with P). The search code is unchanged; the alias is still flagged.

**Pass rule:** every eligible confirmed planet (expected S x 0.66 >= S* = 11.82, at least 3 transits) is recovered:
its peak period matches by item 1 or 5, S >= S*, and it passes the light-curve vetting. No excused misses.
Vetting thresholds are unchanged.
