# exosearch v1.1: implementation (2026-11-10)

v1.0.0 stays frozen (tag `exosearch-v1.0.0`, config hash 80ffc7f29943): none of its modules changed. v1.1 lives in
`exosearch/v11/` with its own version (1.1.0), configuration (`configs/v1.1.json`) and config hash. It implements
`docs/v1.1_plan.md` and the registrations in `docs/preregistration/`. Nothing it produces is called a detection
until the v1.1 freeze.

| item | where | what |
|---|---|---|
| exact-depth S with the out-of-transit term | `v11/search.py` | S = depth_exact · sqrt(N_tr) / CDPP_D · sqrt(1 − D/P) · beta_D / beta'_D. depth_exact is the weighted in-minus-out box mean (the compute_stats depth) at the chosen (P_grid, t0, D). The top 5 distinct scan peaks (first: the registered tie-break choice) are refined and the largest S wins. `S_v10` (v1.0.0 definition at the same peak) and `S_exact` (no out-of-transit term, no beta treatment) are kept. |
| beta treatment | `v11/search.py`, `configs/v1.1.json` | Options a–d of `beta_treatment.md` inside the scan and S. Each option is searched with its own peak and stored (`S_opt_a` … `S_opt_d`, with P, D, t0 and half-width) for the sensitivity rows. The statistic uses `beta_option`, which is **null** until the dated registration that applies the rule. `run work` refuses production while it is null. Option d uses `configs/v1.1_beta_prior.json` (`v11/beta_prior.py`, star-quality beta_D only). |
| prewhitening | `v11/prewhiten.py` | Iterative sinusoid removal above 5 c/d before detrending (amplitude S/N ≥ 4, ≤ 20 terms), logged per star (`pw_prewhiten_n`, `pw_prewhiten_terms`). The comb guard checks A(2f) and A(3f) against a box harmonic ladder (1–6 h at P = m/f, m = 1–3). On a match it does not remove the peak, protects the whole harmonic series f/m · k, and logs it (`pw_prewhiten_comb`). |
| odd/even, secondary | `v11/vet11.py` | Flag only when > 3σ **and** > 10% relative (odd/even vs their mean; secondary vs the primary depth). |
| momentum-dump veto | `v11/vet11.py`, `v11/search.py` | Dumps come from QUALITY bit 32 (desaturation). Transit epochs within 0.1 d of a dump are removed from depth and N_tr before S. The signal is rejected (`momentum_dump`) at ≤ 2 epochs and warned otherwise (`momentum_dump_epoch`). |
| duration cap | `v11/grid.py` | D ≤ 3 · q_circ(P, rho_TIC) · P, or D ≤ 0.1 P without a TIC density (Hippke & Heller 2019). The same function applies to the search, the nulls and the injections. |
| arithmetic | `v11/grid.py`, `v11/kernels.py` | Period grid = fmin + df · arange(n), hashed per row (`grid_sha`). wotan kernels are recompiled with fastmath=False, cache=False, parallel=False. Each process uses an empty numba cache and one thread. |
| tie-break | `v11/search.py` | Plateau rule of `tie_break.md` amendment 1/1a, ported from `host_gate.py`: P = plateau centre, `P_grid_halfwidth` (grid-degeneracy half-width, not a period error), plateau fields, and `period_ambiguous` (transits ≤ 2). |
| provenance, worker guard | `v11/settings.py`, `v11/run.py` | Rows carry `host_id` (opaque h1/h2/h3), `arch`, `lib_versions`, the full `commit`, `config_hash`, `beta_option` and `production`. `run work` refuses a dirty tree, a commit other than the manifest's pinned commit, or a config that differs from the manifest. |
| injections | `v11/pipeline.py`, `configs/injection_v1.1.json` | Same hosts, seeds and draws as injection_v1. 25% are drawn from a "true" density that differs from TIC (unresolved binary, misclassified subgiant, log-uniform 0.01–100×), while the cap still uses TIC. |
| populations | `v11/run.py` | Each star is one job holding its real, flipped, scrambled r0–r2 and injection tasks, so all of a star's runs stay on one host. Hosts are assigned by sha256 of the TIC against fixed weights. |
| beta selection | `v11/beta_select.py` | Applies `beta_treatment.md` as written to the v1.0 interim flipped null and scrambled r0. |
| checks | `v11/run.py compare`, `v11/validate.py` | (a) 3-host gate. (b) Prewhitening/comb-guard and duration-cap injection validation; its pass criteria are fixed in the module docstring. |

Tests: `tests/test_v11.py`.
