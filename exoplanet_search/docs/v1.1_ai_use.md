## 2026-11-11 Task T0 fix (model: Gemini 3.8 Flash, AI agent in the Antigravity CLI)

- `exoplanet_search/exosearch/v11/prewhiten.py`:
  - Replaced unconstrained single-ratio comb guard with multi-harmonic planetary comb test across periods $P \in [0.2, 5.0]$ d.
  - Added harmonic phase consistency check to ensure candidate frequencies point to a common transit epoch $T_0$.
  - Added secondary harmonic verification ($k \cdot f_0$) with simultaneous box ladder amplitude ratio consistency and local noise estimation.
  - Bounded model duration ratio ($m \cdot q < 0.8$) to eliminate poles and prevent false matches on low-frequency stellar activity.
  - Limited comb exclusion series to $h_{\text{max}} = \min(f_{\text{nyq}}/f_0, \lceil 2.5 / (D_{\text{min}} f_0) \rceil)$ with $\pm 2.0/\text{baseline}$ windows capped at 20% spectral coverage.
  - Added comb fundamental period filtering $P \in [0.2, 5.0]$ d on fallback multiples to prevent false comb matches on non-linear stellar harmonics (e.g. HADS stars).
  - Tuned sector coherence parameters (`half_amp_ratio`, `half_cos_phase`) to accommodate beating modes while rejecting transient glitches.
  - All configurable thresholds parameterized from `configs/v1.1.json["prewhiten"]`.
- `exoplanet_search/configs/v1.1.json`:
  - Added new `prewhiten` configuration parameters (`snr_detect`, `comb_durations_d`, `comb_multiples`, `comb_ratio_tol`, `comb_min_snr`, `comb_p_range_d`, `comb_phase_tol`, `comb_max_harmonic_factor`, `comb_exclusion_width`, `comb_max_coverage`, `half_min_snr`, `half_amp_ratio`, `half_cos_phase`).
  - Preserved `beta_option: null` and all other sections.
- `exoplanet_search/exosearch/v11/validate.py`:
  - Added criterion P4 (`pulsator_efficacy`) to `report()` and `all_pass`: tests on seeded synthetic stars with red noise, rotation, and $\delta$ Scuti modes that prewhitening removes pulsations (median $\ge 80\%$, star-level $\ge 50\%$). A policy that removes nothing fails.
