# Welcome to the AstroCompute Lab 🌌

This project is a self-paced learning environment for **Astronomical Data Processing** and **Distributed High-Performance Computing**.

## 🚀 Your Hardware Fleet
| Device | Role | Compute Specs |
| :--- | :--- | :--- |
| **Ubuntu Node** | Primary Dev Node | NVIDIA 1050Ti |
| **Windows WSL** | Secondary Compute | NVIDIA 3050Ti |
| **Intel NUC i7** | Master Scheduler | High CPU/RAM |
| **Raspberry Pi**| Data Scraper | ARM (Low Power) |

## 🛰️ How it Works
1.  **Read the Guide**: Start with the modules in the navigation bar to understand the concepts.
2.  **Open the Notebook**: Each module has a corresponding **Jupyter Notebook** (`.ipynb`) in the root of the repo for hands-on practice.
3.  **Run Across Network**: Once you've learned the local basics, use the **Dask Distributed** module to run your code on all four machines simultaneously!
